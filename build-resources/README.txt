aptPOS Windows packaging assets

- aptpos.ico: multi-size Windows application and installer icon
- aptpos-logo.svg: editable vector brand artwork
- installerHeader.bmp: NSIS installer header image (150 x 57)
- installerSidebar.bmp: NSIS wizard side image (164 x 314)
- TERMS.txt: installer terms shown before installation
- custom-installer.nsh: branded NSIS welcome page

The Windows installer is built from the project root with npm run electron:build.
